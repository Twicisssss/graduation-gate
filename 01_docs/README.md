# 文档索引

本目录集中存放所有**文字类成果**，按阶段分文件夹，文件用「阶段-内容-版本」命名，避免 `最终版2(改).docx`。

## 目录

| 路径 | 内容 | 当前状态 |
| --- | --- | --- |
| `01_task/` | 任务书（模板、已填写稿）、下发通知 | 模板已存，待填写 |
| `02_proposal/` | 开题报告、文献综述 | 未开始 |
| `03_thesis/` | 论文正文、查重报告、附表 | 未开始 |
| `04_defense/` | 答辩 PPT、讲稿、预答辩记录 | 未开始 |
| `模块清单与引脚规划.md` | 硬件 BOM、引脚分配、软件模块表 | 已完成（初稿） |
| `选题与需求.md` | 平台题目原文、我的理解与关键决策 | 已完成 |
| `进度日志.md` | 每周进度与问题记录 | 持续更新 |

## 命名约定

```
02_proposal/开题报告-v1.0-20261215.docx
03_thesis/论文-v0.3-第3章-20270320.docx
04_defense/答辩PPT-v2.0-20270510.pptx
```

规则：`内容 - 版本号 - 日期`。版本号用 `v主.次`，主版本号变了说明结构大改，次版本号是内容迭代。

## 提醒

- 论文每改一版另存新文件，**不要覆盖**——目录里留得下，答辩时老师问"上一版怎么写的"能立刻翻出来。
- 查重报告、导师批注版单独放，不要混在正文文件里。
- 任务书模板是 2025 版（对应 2026 届），2027 届的正式文件以学院下发为准，拿到后放 `01_task/`。
