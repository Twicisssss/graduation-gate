# 参考资料（07_refs）

课题要求"查阅近五年与本课题相关的文献"，这里统一存放文献与本项目要引用的规范。

## 建议放什么

- **文献 PDF**：知网/万方下载的论文，按 `作者-年份-标题.pdf` 命名
- **标准与规范**：《武汉纺织大学本科毕业设计(论文)工作条例》、GB/T 7714 参考文献格式
- **竞品资料**：市面门禁产品手册、方案商白皮书（写"研究现状"用）
- **阅读笔记**：`文献笔记.md`，一条文献一行，写"结论 + 可借鉴点 + 是否引用"

## 文献笔记模板

| 序号 | 文献 | 年份 | 核心结论 | 可借鉴点 | 是否引用 |
| --- | --- | --- | --- | --- | --- |
| 1 |  |  |  |  | 是/否 |

## 命名与体积

```
07_refs/2023-张三-多因子身份认证在门禁系统的应用.pdf
```

单文件超过 20 MB 的手册不要提交进仓库（会拖慢 clone），在本文档里写下载链接即可。
